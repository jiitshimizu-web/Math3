基礎数学Ⅰ 演習 Ver3.1

【使い方】
ZIPをすべて展開し、index.htmlをChromeまたはEdgeで開いてください。
インストール・通信不要。HTML/CSS/JavaScript分離の完全ローカル教材です。

【問題数】
第1〜15回：各50問（第2回は生活の文章問題50問に変更）
第16回 総合演習：130問（既存10問＋新しい複合文章問題120問）
第17回 期末試験・解説：10問
合計890問。問題数は固定で、シャッフルは表示順のみ変更します。

【学習】
1. 単元を選び、例題を確認します。
2. 10問ずつ解きます。問題指定の単位で、単位文字を省いて答えます。
3. 「解く順番・注意点」でヒントを確認します。
4. 「解き方を1段階ずつ」または「すべての解き方・答え」を開きます。
5. 採点し、復習を「間違えた問題」にすると再挑戦できます。
6. 分数は1/2のように入力。1/2、2/4、0.5を同じ値として採点します。
   比は2:3、文字式は6x+2のように入力してください。
   文字式の採点は、空白や全角を統一した文字列比較です。
   同じ意味でも順序を入れ替えた式などは自動では同一判定しません。

【図とアニメーション】
例題の「動かして理解する図」を開いてスライダーまたは再生で確認。
数直線、割合、三角形の面積、比例グラフ、計算順序を収録。
問題内の図は模式図で、実際の寸法比とは一致しないことがあります。

【保存・再開】
答えと採点結果はブラウザ内に自動保存。
削除やPC変更に備え、「学習記録をJSON保存」で記録を保存してください。
「記録を読み込む」は現在の記録をそのJSONの内容で置き換えます。
問題の表示ページは保存せず、再開は単元の先頭から表示します。

【印刷】
「問題を印刷」「解説を印刷」は現在表示中の最大10問を印刷します。
印刷ダイアログで「PDFに保存」も可能です。
